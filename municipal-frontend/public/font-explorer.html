Which voice should welcome the public?

Every option below uses the same municipal-transparency content. Compare the way the type handles a public promise, a search task, and a procurement record—not just how its alphabet looks in isolation.

12 visual options same content desktop + mobile ready
Best overall: Public Sans

Clear, public-minded, and unusually good in dense records.

Use one family for the whole public portal. It feels official without becoming cold, its larger x-height keeps labels readable, and it keeps headings, search, and long project names in one coherent voice.

Strong alternate: Noto Sans

The safest choice for a multilingual municipal service.

Choose this if Filipino, local-language, or future multilingual coverage is central. It is less distinctive, but it is a dependable, calm workhorse with broad language support.
